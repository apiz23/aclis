2

Persediaan Pangkalan Data (Supabase)

  1. Pergi ke Supabase Dashboard → pilih projek anda
  2. Buka SQL Editor di panel kiri
  3. Jalankan migrasi skema penuh (salin & tampal):
// Skema ACLIS — jalankan sekali sahaja
supabase/migrations/0010_aclis_full_schema.sql
  1. Jalankan data awal untuk pengguna aplikasi:
supabase/aclis_app_user_rows.sql
Catatan: Fail 0010_aclis_full_schema.sql mengandungi semua jadual ACLIS (mukim, kampung, pemimpin, penduduk, laporan, isu, penilaian, pengguna, audit). Gunakan IF NOT EXISTS — selamat dijalankan berulang kali.
3

Muat Turun & Muat Naik Foto Ketua Kampung

  1. Fail aclis-leader-photos.zip terdapat di data/raw/aclis-leader-photos.zip
  2. Ekstrak fail zip tersebut
  3. Buka Supabase Dashboard → Storage → pilih bucket aclis-leader-photos
  4. Klik Upload → pilih semua fail foto yang diekstrak
Catatan: Fail mestilah dalam format .jpg atau .png. Saiz maksimum 5MB seimbang. Nama fail akan digunakan sebagai photo_url dalam jadual aclis_leader.

Persediaan Backend (FastAPI)

# Buka folder backend
cd backend

# Cipta persekitaran maya
python -m venv .venv

# Aktifkan persekitaran maya
.venv\Scripts\activate           # Windows

Fail .env

Cipta fail .env daripada template:

cp .env.example .env

编辑 .env dan isi nilai berikut:

Pemboleh UbahStatusKeterangan
SUPABASE_URLWajibURL projek Supabase (cth: https://xxxx.supabase.co)
SUPABASE_JWT_SECRETWajibRahsia JWT — Supabase → Settings → API
SUPABASE_SERVICE_ROLE_KEYWajibKunci service role (untuk bypass RLS)
CORS_ORIGINSWajibURL frontend — pisahkan dengan koma (cth: http://localhost:3000)
AI_PROVIDERWajibmock (tanpa AI) atau groq (dengan AI)
GROQ_API_KEYJika groqKunci API Groq — console.groq.com
GROQ_MODELPilihanDefault: llama-3.3-70b-versatile

Mula Pelayan

# Windows (laluan dengan ruang)
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

# macOS / Linux
python -m uvicorn app.main:app --reload --port 8000
Kejayaan: Backend berjalan di http://localhost:8000. API docs di http://localhost:8000/docs.
Windows — ralat "uv trampoline failed"?
Path projek mengandungi ruang (Desktop\Developer\aclis). Gunakan .venv\Scripts\python.exe -m uvicorn seperti di atas — jangan guna uvicorn secara langsung.

Cipta Pengguna Admin Pertama

  1. Pergi ke Supabase Dashboard → Authentication → Users
  2. Klik Add user — masukkan e-mel dan kata laluan
  3. Salin UUID pengguna baru (terdapat pada halaman pengguna)
  4. Buka SQL Editor dan jalankan:
UPDATE auth.users
SET raw_app_meta_data = raw_app_meta_data || '{"role": "admin_daerah"}'::jsonb
WHERE id = 'uuid-pengguna-di-sini';
PerananHuraian
admin_daerahAkses penuh — urus semua kampung dan pengguna
ketua_kampungUrus kampung sendiri sahaja
penghuluLihat data mukim sendiri sahaja
