# ACLIS

### AI Community Leadership Intelligence System

Sistem web untuk mengurus data Ketua Kampung dan Penghulu bagi Pejabat Daerah Pontian, Johor.

---

## Tentang Sistem

ACLIS menumpukan data kepimpinan kampung daripada hamparan tebaran (spreadsheet) kepada satu platform web yang terpusat. Sistem ini membolehkan pentadbir daerah, ketua kampung, dan penghulu mengurus maklumat, laporan bulanan, isu komuniti, dan penilaian prestasi — semuanya di satu tempat.

---

## Modul Utama

| # | Modul | Penerangan |
|---|---|---|
| 1 | **Profil Kampung** | Pengurusan maklumat kampung termasuk koordinat GPS, jumlah penduduk B40, dan profil asas |
| 2 | **Data Penduduk & B40** | Senarai penduduk mengikut kampung dengan penandaan status B40 |
| 3 | **Laporan Bulanan** | Penyerahan dan pengurusan laporan bulanan dengan penandaan status (draf / dihantar / lewat) |
| 4 | **Isu Komuniti** | Pelaporan isu komuniti dengan pengelasan automatik menggunakan AI |
| 5 | **Papan Pemuka** | Paparan statistik visual dengan carta dan amaran laporan lewat |
| 6 | **Analitik AI** | Ringkasan laporan dan trend insights menjana automasi AI |

### Ciri Tambahan

- **Pemimpin** — profil Ketua Kampung / Penghulu dengan muat naik foto dan skor penilaian
- **Peta** — paparan peta untuk isu komuniti dan pemilihan koordinat GPS
- **Direktori** — carian pantas profil pemimpin dan kampung
- **Borang** — borang laporan bulanan berasingan (Seksyen A–D)
- **Pengumuman** - papan pengumuman daerah
- **Audit Jejak** — log lengkap untuk setiap perubahan data (pematuhan PDPA)

---

## Peranan Pengguna

| Peranan | Keterangan |
|---|---|
| **Pentadbir Daerah** | Akses penuh kepada semua data dan kampung |
| **Ketua Kampung** | Mengurus data kampung sendiri; menghantar laporan; melaporkan isu |
| **Penghulu** | Melihat data kampung dalam mukim sendiri |

- **Navi** — warna utama (`#0C2340`)
- **Emas** — warna aksen (`#C4922A`)
- **Font** — Figtree (badan), Barlow Semi Condensed (tajuk), JetBrains Mono (kod)
